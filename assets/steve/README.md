# Steve assets

`urdf/steve_minimal.urdf` + `meshes/` are generated by `tools/build_minimal_urdf.py` from the
`steve_isaacsim` repo (`steve_new_gripper.urdf`, branch state of 2025-08-08, itself xacro output
of `steve_description`). They are committed so this project is independent of both source repos.
`urdf/steve_holonomic.urdf` is derived from the minimal URDF by `tools/make_holonomic_urdf.py` (adds a
world anchor and virtual x/y/yaw joints under `base_link`; robot part byte-identical, enforced by a test).
`usd/free/` and `usd/holonomic/` are generated by `scripts/convert_urdf.py [--variant holonomic]` and not committed.

## Contents
Neobotix MPO-700 base (4 caster + 4 wheel joints) · cabinet · UR5e (6 joints) · Robotiq 2F-85
(1 driven + 5 mimic joints). Removed: IMU, 2 lidars, pan-tilt tower, Dynamixels, L515, wrist
camera mount, D405, all Gazebo / transmission blocks.

## Deviations from the source URDF (all in `PATCHES` in the build script)
| Change | Why |
|---|---|
| Gripper links: inertia `1.0` -> `1e-6` kg m^2 (mass unchanged, 0.002 kg) | placeholder inertia was ~500x too large for the mass |
| Frame-only links get mass 1 g / inertia 1e-7 | importer otherwise assigns **1 kg each** (5 kg phantom mass, 3 kg at the wrist) |
| Names/mesh stems: non `[A-Za-z0-9_]` -> `_` (`ur5e_flange-tool0` -> `ur5e_flange_tool0`, `MPO-700-BODY.dae` -> `MPO_700_BODY.dae`) | USD prim names; importer fails on hyphenated mesh names and silently renames joints |
| Empty `<material name="">` named uniquely; `<material>` removed from `<collision>` | invalid / ambiguous URDF |
| `.dae` files without `<unit>` (all Robotiq) get `<unit meter="1"/>` | **importer hangs forever** without it |
| Mesh paths rewritten to relative `../meshes/...` | no ROS package path or `/workspace` container needed |

Meshes are in millimetres although the DAEs declare metres; the URDF `scale="0.001"` handles it.
Mesh licences (Neobotix, Universal Robots, Robotiq) have not been checked: do not publish this
repo without doing so.

## Not verified against the real robot
UR5e mount yaw (0 here, pi/2 in the older ROS 1 model), cabinet x-offset (0.072 here, 0.025 in
the ROS 1 `neo_mpo_700` model), caster/wheel inertias (caster: 9 kg with ~4e-4 kg m^2).
